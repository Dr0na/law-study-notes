# SPPU LLB Answer Writing Rules

## Purpose

This document defines the mandatory answer-writing standards for all study material generated by the system.

These rules are derived from:

* SPPU LLB examination patterns
* University answer-writing expectations
* Legal drafting principles
* High-scoring answer structures

All generated content must comply with these rules.

---

# Primary Objective

Generate content that helps a student:

* Understand the concept
* Remember the concept
* Revise the concept
* Reproduce the answer in examinations
* Score maximum marks

The system is examination-focused.

The goal is not merely knowledge transfer.

The goal is answer reproduction under examination conditions.

---

# Core Principles

Every answer must be:

* Legally accurate
* Examination oriented
* Pointwise
* Structured
* Easy to revise
* Easy to memorize
* Suitable for SPPU answer sheets

---

# Mandatory Answer Structure

Every topic must contain:

```text
Definition

Introduction

Main Content

Case Laws

Conclusion
```

No answer may omit any of these sections.

---

# Heading Rules

Every answer must use hierarchical headings.

Example:

```markdown
# Quasi Contract

## Definition

## Essentials (5)

### 1. Lawful Benefit

### 2. Non-Gratuitous Act

### 3. Obligation Imposed By Law
```

---

# Count Display Rule

Whenever a list exists, the count must appear in the heading.

Correct:

```markdown
## Essentials (5)
```

Incorrect:

```markdown
## Essentials
```

---

# Mandatory Counted Sections

The following sections must always include counts where applicable:

* Essentials
* Characteristics
* Elements
* Conditions
* Exceptions
* Classifications
* Principles
* Doctrines
* Articles
* Sections
* Amendments
* Case Laws

---

# Definition Rule

Every topic begins with a definition.

Definition should:

* Be legally accurate
* Be concise
* Be examination friendly

Preferred order:

```text
Statutory Definition

Textbook Definition

Exam Definition
```

---

# Introduction Rule

Every answer must contain:

```text
Context

Purpose

Importance
```

The introduction should be brief.

Avoid lengthy narrative paragraphs.

---

# Main Body Rule

The body must be:

* Pointwise
* Structured
* Logically ordered

Avoid essay-style writing unless specifically required.

---

# Explanation Rule

Each point should follow:

```text
Heading

Explanation

Example (if applicable)
```

---

# Illustration Rule

Whenever possible include:

* Legal illustrations
* Practical examples
* Examination examples

Examples improve retention and scoring.

---

# Language Rules

Use:

* Formal legal language
* Examination-friendly language
* Plain English

Avoid:

* Excessive jargon
* Conversational language
* Unnecessary complexity

---

# Formatting Rules

Use:

* Markdown headings
* Bullet lists
* Numbered lists
* Tables where appropriate

Avoid:

* Large unstructured paragraphs

---

# Marks-Based Expansion Rules

## 5 Marks

Target:

```text
800–1200 words
```

Focus:

* Essentials
* Definition
* Key case law

---

## 10 Marks

Target:

```text
1500–2500 words
```

Focus:

* Detailed explanation
* Multiple case laws
* Comparative analysis

---

## 15 Marks

Target:

```text
2500–4000 words
```

Focus:

* Comprehensive treatment
* Statutory provisions
* Articles
* Amendments
* Case laws
* Criticism
* Examination insights
