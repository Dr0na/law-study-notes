# output-specification.md

# SPPU LLB Output Specification

## Purpose

This document defines the exact structure, format, organization, naming conventions, and quality requirements for all outputs generated by the SPPU LLB Autonomous Study Material Generation System.

This is the authoritative specification for all deliverables.

---

# Output Philosophy

The generated output must be:

* Examination-oriented
* Student-friendly
* Legally accurate
* Revision-friendly
* Visually organized
* NotebookLM-compatible
* SPPU-compliant

The system should generate content that is immediately usable for examination preparation.

---

# Output Root

All generated content must be written under:

```text
.temp/
```

No output may be generated outside:

```text
.temp/
```

---

# Output Categories

The system produces six categories of deliverables.


# Subject Naming Convention

Use:

```text
Subject_Name
```

Examples:

```text

Jurisprudence

```

Avoid:

```text
constitutional law ii

constitutional-law-ii
```
