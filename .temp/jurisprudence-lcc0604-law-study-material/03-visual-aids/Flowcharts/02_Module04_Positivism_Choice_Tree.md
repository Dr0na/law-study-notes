# 📐 Flowchart — choosing the right positivist (Module 04)

```mermaid
flowchart TD
    Q["Question on legal positivism"]
    Q --> A{"Is the question about sovereignty + sanction?"}
    A -- Yes --> AU["Use AUSTIN<br/>Command + Sovereign + Sanction + Duty (CSSD)"]
    A -- No --> B{"Is it about the structure of rules and validity?"}
    B -- Yes --> HA["Use HART<br/>Primary + Secondary; Rule of Recognition (RCA)"]
    B -- No --> C{"Is it about pure form / hierarchy of norms?"}
    C -- Yes --> KE["Use KELSEN<br/>Pure Theory + Stufenbau + Grundnorm"]
    C -- No --> D{"Is it about reform / utilitarian justification?"}
    D -- Yes --> BE["Use BENTHAM<br/>Expositorial + Censorial; Utility"]
    D -- No --> COMP["Use comparative essay (BAHK in sequence)"]
```

**Reading guide:**

- *“Define law”* type — start with **Austin**, then critique with **Hart**.
- *“Validity of law”* type — anchor on **Hart’s rule of recognition** or **Kelsen’s Grundnorm**.
- *“Punishment / reform of law”* type — bring in **Bentham’s utility**.
- **BAHK** is the safe sequence for any *“discuss positivism”* essay.
