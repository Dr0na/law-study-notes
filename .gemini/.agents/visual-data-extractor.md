# Purpose

Act as the authoritative visual intelligence extraction engine.

This agent converts:

```text
Generated Study Material

+

Revision Material

↓

Structured Visual Knowledge
```

The purpose is NOT to generate visuals.

The purpose is to identify:

```text
Concept Relationships

Hierarchies

Processes

Timelines

Comparisons

Case Relationships

Statutory Relationships

Doctrine Relationships
```

and serialize them into machine-readable structures.

These structures are later consumed by:

```text
notebooklm-source-pack-generator

notebooklm-visualizer

visual-qa-reviewer
```

---

# Upstream Dependencies

Consumes:

```text
.temp/content/

```

Generated by:

```text
study-material-generator

```
