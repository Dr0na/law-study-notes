# One-Page Rules and Cases

| Rule / question | Recall | Leading authority |
|---|---|---|
| Ordinary meaning | Start with enacted words in context | *Kanai Lal Sur* |
| Avoid absurdity | Golden rule; make smallest permissible adjustment | *Grey v. Pearson* (1857) 6 HLC 61 |
| Suppress mischief | Prior law → defect → remedy → remedy-advancing construction | *Heydon's Case* |
| Harmonise provisions | Give effect to all parts if possible | *CIT v. Hindustan Bulk Carriers* |
| Meaning from associates | Noscitur a sociis | *Rohit Pulp* |
| General words after specific list | Ejusdem generis; first establish a genus | *Amar Chandra Chakraborty* |
| Repeal savings | Accrued rights/proceedings generally preserved absent contrary intent | GCA s.6; *Mohar Singh* |
| Civil court ouster | Not lightly inferred; check special remedy and exceptions | *Dhulabhai* |
| Constitutional review | Tribunal decisions remain reviewable by constitutional courts | *L. Chandra Kumar* |
| Basic structure | Art.368 cannot destroy core structure | *Kesavananda Bharati* |
| Tax imposition | No tax by implication; charge must be clear | *A.V. Fernandez* |
| Mens rea | Presumed unless excluded by text/context | *Nathulal*; *Mayer Hans George* |
| Beneficial statute | Advance remedy where text permits | *B. Shah* |
| Company officers | Vicarious criminal liability requires statutory ingredients | *S.M.S. Pharmaceuticals* |
| Mandatory/directory | Purpose, consequences, prejudice, scheme | *Sharif-ud-Din* |

## Mimansa cue: “S-L-V-P-S-S”

**S**hruti (express text), **L**inga (indication), **V**akya (sentence), **P**rakarana (context), **S**thana (position), **S**amakhya (title/designation). Apply as contextual interpretive aids, not as a replacement for statute.
