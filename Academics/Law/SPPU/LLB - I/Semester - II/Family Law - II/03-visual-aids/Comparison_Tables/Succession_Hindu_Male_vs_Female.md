# Comparison: Succession to Hindu Male vs Hindu Female Property

| 📊 Basis | 👨 Hindu Male (Sec 8) | 👩 Hindu Female (Sec 15) |
| :--- | :--- | :--- |
| **First Heirs** | Class I heirs (son, daughter, widow, mother, etc.). | Sons, daughters, and husband. |
| **Order** | Class I → Class II → Agnates → Cognates → Escheat. | Children & husband → Heirs of husband → Parents → Heirs of father → Heirs of mother. |
| **Special Rule** | No special rule based on source of property. | **Sec 15(2):** Property inherited from father goes to father's heirs. Property from husband goes to husband's heirs. |
| **Nature of Estate** | Absolute ownership. | Absolute ownership (Sec 14 abolished limited estate). |
| **Escheat** | Sec 29 — Government takes if no heir. | Same. |
