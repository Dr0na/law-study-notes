# 📜 Answer Writing Template — Jurisprudence

> Topper-style scaffold. Use this for every answer; the marks-band only changes the *depth*, not the *structure*.

## 1. Universal scaffold

```text
[Synopsis box — 3 bullets for 10/15 marks]
[Introduction — definition + context — 1 para]
[Body — numbered sub-heads with hybrid bullets + prose]
[Cases — 1–4 leading authorities, properly cited]
[Diagram / Table — embed where hierarchy or comparison helps]
[Criticism — 2–3 lines]
[Conclusion — analytical close + Indian touch]
```

## 2. By marks band

### 5 marks (≈ 300–400 words)

1. **Introduction** — 2-3 lines (definition + thinker).
2. **Body** — numbered points (3–5) with one-line each.
3. **One case** if directly relevant.
4. **Conclusion** — single sentence.

### 10 marks (≈ 500–700 words)

1. **Synopsis** — 3–4 bullets.
2. **Introduction** — short paragraph.
3. **Body** — 4–6 sub-heads, hybrid bullets + prose.
4. **Cases** — 1–3 cases.
5. **Criticism** — 2-3 lines.
6. **Conclusion** — analytical close.

### 15 marks (≈ 800–1200 words)

1. **Synopsis** — 4–5 bullets.
2. **Introduction** — definitions of 2–3 jurists.
3. **Body** — 5–8 sub-heads, with at least one **table** and one **flowchart**.
4. **Cases** — 2–5 cases with brief facts and holding.
5. **Criticism + counter-criticism**.
6. **Indian application** — *Maneka Gandhi*, *Kesavananda*, *Mehta*, etc.
7. **Conclusion** — synthesis + theory-policy bridge.

## 3. Topper habits

- **Define every term** before using it.
- **Name the school** — natural law / positivist / realist / sociological — even if the question doesn’t.
- **Cite mnemonics** sparingly (`As I memorise it — ACPRCC`).
- **Use Hohfeldian language** when discussing rights.
- **Always close with a balanced critique** — never one-sided.

## 4. Common mistakes to avoid

1. Listing thinkers without explaining their theory.
2. Confusing **ratio** with **obiter**.
3. Quoting *Rylands* but failing to mention *M.C. Mehta* in the Indian context.
4. Treating **Austin** as the whole of positivism.
5. Omitting **Article 141** when discussing precedent.
6. Writing **natural law** essays without naming **Fuller** or **Finnis** for the revival.
7. Skipping the **Indian touchpoint** — examiners reward home jurisprudence.
8. Over-fragmenting bullets — keep paragraphs of 2-3 lines around each head.

> 🧠 **Two-minute checklist before submitting:** definition? mnemonic-based list? case? table or flowchart? Indian touch? critique? conclusion?
