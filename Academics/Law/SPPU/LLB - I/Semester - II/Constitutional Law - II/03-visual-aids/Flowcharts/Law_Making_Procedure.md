## 🔹 Stage-by-Stage Flow

```
                    BILL INTRODUCED
                          |
                    In Either House
                   (Lok Sabha or Rajya Sabha)
                          |
                          ↓
    ┌─────────────────────────────────────────┐
    │     STAGE 1: FIRST READING              │
    │     - Leave to introduce                │
    │     - Bill introduced & published       │
    │     - Objectives explained              │
    └─────────────────────┬───────────────────┘
                          ↓
    ┌─────────────────────────────────────────┐
    │     STAGE 2: SECOND READING             │
    │                                         │
    │     STAGE A: General Discussion         │
    │     - Debate on principles              │
    │     - Options:                          │
    │       • Take up immediately             │
    │       • Refer to Select Committee       │
    │       • Refer to Standing Committee     │
    │       • Circulate for opinion           │
    │                                         │
    │     STAGE B: Clause-by-Clause          │
    │     - Each clause debated               │
    │     - Amendments moved                  │
    │     - Voting on clauses                 │
    └─────────────────────┬───────────────────┘
                          ↓
    ┌─────────────────────────────────────────┐
    │     STAGE 3: THIRD READING              │
    │     - Final debate on entire bill       │
    │     - Only minor amendments             │
    │     - Vote taken                        │
    │     - If passed → Transmitted          │
    └─────────────────────┬───────────────────┘
                          ↓
    ┌─────────────────────────────────────────┐
    │     STAGE 4: OTHER HOUSE                │
    │     (Same 3 stages repeated)            │
    │     - First Reading                     │
    │     - Second Reading                    │
    │     - Third Reading                     │
    └─────────────────────┬───────────────────┘
                          ↓
                    Both Agree?
                          |
            ┌─────────────┴─────────────┐
            │                           │
           YES                          NO
            │                           │
            ↓                           ↓
    ┌──────────────┐         ┌──────────────────┐
    │ PRESIDENT'S  │         │  DEADLOCK        │
    │   ASSENT     │         │  (Article 108)   │
    │ (Article 111)│         └────────┬─────────┘
    └──────┬───────┘                  │
           │                          ↓
           │              ┌─────────────────────┐
           │              │  JOINT SITTING      │
           │              │  - President calls  │
           │              │  - Speaker presides │
           │              │  - Simple majority  │
           │              │  - Lok Sabha view   │
           │              │    prevails (543 vs │
           │              │    245 members)     │
           │              └────────┬────────────┘
           │                       │
           │                       ↓
           │              To President for Assent
           │                       │
           └───────────────────────┘
                          ↓
            ┌─────────────────────────────┐
            │   PRESIDENT'S OPTIONS       │
            │   1. Give Assent → Act      │
            │   2. Withhold → Dies        │
            │   3. Return once (not Money)│
            │      If passed again → Must │
            │      give assent            │
            └─────────────┬───────────────┘
                          ↓
                     BECOMES ACT
```

## 💰 Money Bill - Special Procedure

```
        MONEY BILL (Article 110)
                |
         Only in Lok Sabha
         (Cannot originate in RS)
                ↓
         Lok Sabha passes
         (Normal 3 stages)
                ↓
         Transmitted to
          Rajya Sabha
                ↓
    ┌───────────────────────────┐
    │  RAJYA SABHA: 14 DAYS MAX │
    └──────┬────────────┬────────┘
           │            │
    Returns with    Doesn't return
    recommendations  in 14 days
           │            │
           ↓            ↓
    Lok Sabha may   Deemed passed
    accept/reject       │
           │            │
           └─────┬──────┘
                 ↓
         President's Assent
         (Cannot return)
                 ↓
            BECOMES ACT

Note: Lok Sabha has FINAL SAY
      Rajya Sabha can only RECOMMEND
```

## 🔄 Constitutional Amendment Procedure

```
      AMENDMENT BILL (Article 368)
                |
         Introduced in
         either House
                ↓
    ┌───────────────────────────┐
    │  SPECIAL MAJORITY NEEDED  │
    │  - 2/3 present & voting   │
    │  - Majority of total      │
    └──────────┬────────────────┘
               ↓
         First House passes
         (Special majority)
               ↓
         Second House passes
         (Special majority)
               ↓
    ┌───────────────────────────┐
    │  Type of Amendment?       │
    └──┬──────────────────────┬─┘
       │                      │
  Simple/Special         Needs State
   majority only        Ratification
       │                      │
       ↓                      ↓
  President's      50% State Legislatures
    Assent             must ratify
       │                      │
       └──────────┬───────────┘
                  ↓
            AMENDMENT DONE
```

**Which Need State Ratification:**
- Election of President
- Union-State power distribution
- High Courts provisions
- Representation of States in Parliament
- Article 368 itself

## ⚡ Quick Reference - Time Limits

| Stage | Time Limit |
|-------|------------|
| **Rajya Sabha** (Money Bill) | 14 days max |
| **Rajya Sabha** (Ordinary Bill) | No limit (but Joint Sitting if prolonged) |
| **Ordinance** validity | 6 weeks after Parliament reassembles |
| **Joint Sitting** gap | No specific limit |
| **President's Assent** | No time limit (pocket veto possible) |

## 🧠 Memory for Stages

**Ordinary Bill = "I-D-P-O-J-A"**  
**I**ntroduce, **D**iscuss, **P**ass, **O**ther house, **J**oint (if needed), **A**ssent

**Money Bill = "L-R14-L-P"**  
**L**ok Sabha, **R**ajya (14 days), **L**ok decides, **P**resident assent
